# DIY同城门户分类信息发布求职招聘房产汽车二手交易转让门户APP/小程序uniapp

源码地址：ym7k.com/19279/

基于 uni-app 开发的 DIY 同城门户分类信息系统，一套前端代码，可打包微信小程序、H5、安卓 / IOS APP，对标同城综合信息门户，求职招聘、房产租售、汽车交易、二手转让、本地便民板块自由开关、自定义搭建，适合打造县域、市级本地生活信息平台，自主按需搭配业务模块，自由度高，二次开发灵活。

平台主打 DIY 自定义门户，运营者可以自由配置首页布局、图标菜单、板块开启关闭，想要做纯招聘站、房产平台，或是全品类综合同城门户都可以灵活调整。内置主流信息大类：求职招聘、房产租售、汽车买卖、二手物品转让、商铺转让、家政便民、本地服务、顺风车等，每个分类独立表单、独立筛选条件，适配不同信息发布场景。

✅ 用户端多端互通（APP / 小程序 / H5）
LBS 定位自动匹配同城，可切换城市、区县，按距离就近展示信息。普通用户一键发布图文信息：

- **求职招聘板块**：个人投递简历、企业发布全职、兼职、零工岗位；支持企业资质审核、简历查看、岗位置顶、在线私信沟通；
- **房产板块**：住宅出租出售、合租、商铺、厂房仓库，户型、面积、租金、配套标签齐全，支持预约看房；
- **汽车板块**：二手车转让、新车导购、租车、维保信息；
- **二手转让板块**：数码、家具、家电、闲置物品、设备转让，支持标价、议价；
- **便民信息**：搬家、维修、家政、招商加盟、本地商铺转让等。

发布信息支持多图上传、价格设置、联系电话、私信咨询；自带收藏、浏览记录、消息通知、一键分享，可设置付费刷新、置顶、加急曝光，提升信息曝光量。

✅ 企业 / 商家入驻
商家、中介、劳务公司、二手车商、房产中介独立入驻认证，专属发布权限，可批量发布房源、车源、招聘岗位；支持开通商家主页，集中展示全部信息，配套会员套餐，长期享受曝光权益。

✅ PC 总后台，DIY 可视化配置
后台支持自由拖拽、开启关闭各个业务模块，自定义分类、字段、首页导航、轮播广告、弹窗公告；统一审核全部信息，管控虚假房源、虚假招聘、违规二手信息；支持多城市分站、区域代理；充值订单、置顶流水、提现、举报投诉、用户认证、数据统计看板齐全。支付、会员、置顶、刷新、联系解锁、广告位多套变现渠道，按需开启。

## ✨ 核心优势：uniapp 跨端 + DIY 灵活搭建

- **uni-app 一套代码多端打包**：微信小程序、H5、安卓、苹果 APP，一套源码维护，降低多端开发成本；
- **高度 DIY 自定义门户**：不用改代码，后台即可调整首页菜单、开启或关闭招聘、房产、二手车、二手板块，想做垂直站或者综合同城门户自由切换；
- **独立私有化部署**：源码交付，数据自主掌控，前后端分离架构，方便新增模块；
- **本地化 LBS 同城流量**：按距离排序、同城优先，非常适合县城、地级市本地运营；
- **丰富拓展空间**：可叠加团购、同城商圈、跑腿、论坛、本地探店等功能。

不管你想做综合同城信息港，单独运营本地招聘平台、二手房平台、二手车交易平台，还是二手闲置转让市场，这套 uniapp 同城门户系统都可以按需改造，快速上线本地同城门户。
